# Personal AI Assistant

## Назначение

Этот репозиторий — главный источник истины для памяти и логики личного ИИ-ассистента предпринимателя.

Все изменения памяти ассистента вносятся только через подтверждённые решения пользователя.

Google Drive используется для рабочих документов бизнеса, но не как основная память ассистента.

## Структура

- `ASSISTANT.md` — роль и рабочий контекст ассистента.
- `KNOWLEDGE.md` — подтверждённые знания и память ассистента.
- `DECISIONS.md` — подтверждённые решения пользователя.
- `CHANGELOG.md` — журнал изменений репозитория.
- `ROADMAP.md` — план дальнейшего развития.
- `prompts/` — рабочие промпты.
- `rules/` — подтверждённые правила работы и автоматизаций.
- `projects/` — материалы по отдельным направлениям.

Детальное содержимое будет перенесено из текущих согласованных документов после создания репозитория.
