# Личный ИИ-ассистент предпринимателя

## Назначение

Репозиторий хранит подтверждённую память и логику личного ИИ-ассистента предпринимателя. GitHub — главный источник истины. Google Drive используется для рабочих документов бизнеса, но не как основная память ассистента.

## Архитектура работы

1. ChatGPT анализирует Gmail, Calendar, Drive, Sheets, проекты и ежедневные события.
2. ChatGPT предлагает новые правила и готовит точные задания.
3. Пользователь подтверждает решения и передаёт задания в Codex.
4. Codex изменяет файлы репозитория, показывает diff, делает commit и push.
5. GitHub хранит подтверждённую актуальную версию памяти и логики.

Изменение памяти возможно только после явного подтверждения пользователя.

## Основные файлы

- `ASSISTANT.md` — действующая архитектура и принципы работы ассистента.
- `KNOWLEDGE.md` — действующие подтверждённые правила и знания.
- `DECISIONS.md` — решения пользователя с датами.
- `CHANGELOG.md` — журнал изменений памяти и проекта.
- `ROADMAP.md` — приоритеты дальнейшего развития.
- `prompts/` — задания для ежедневного обзора и обучения.
- `rules/` — подробные правила Gmail, ярлыков и автоматизаций.
- `projects/` — краткий контекст отдельных проектов.

## Рабочий цикл

ChatGPT анализирует информацию и готовит задание. Пользователь подтверждает его и передаёт в Codex. Codex меняет только нужные файлы, показывает diff, делает commit и push. После этого результат повторно проверяется в репозитории.

## Правило проверки

Изменение считается выполненным только после проверки diff, commit, push и повторного чтения файла из репозитория.
