# Рабочий цикл обучения

1. ChatGPT выявляет новый повторяющийся случай.
2. Сравнивает его с действующими правилами.
3. Если правило новое — формулирует предложение.
4. Пользователь подтверждает или отклоняет его.
5. После подтверждения ChatGPT пишет точную инструкцию Codex.
6. Codex изменяет `KNOWLEDGE.md` и/или `DECISIONS.md`.
7. Codex обновляет `CHANGELOG.md`.
8. Codex показывает diff.
9. Codex делает commit и push.
10. ChatGPT проверяет отчёт.
11. Только после этого правило считается активным.

## Запреты

- Не обучаться на одном неоднозначном случае.
- Не добавлять правило без подтверждения.
- Не переписывать несколько файлов без необходимости.
- Не скрывать ошибку.
- Не считать действие выполненным без проверки.
